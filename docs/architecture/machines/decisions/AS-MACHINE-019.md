# AS-MACHINE-019 — Возврат несовместимых ресурсов и полное принудительное опустошение

**Статус:** утверждено  
**Область:** архитектура машин Astral Space  
**Последнее согласование:** 2026-11-01  
**Связанные решения:** [Реестр ADR](../README.md#реестр-решений)


## Решение
- После смены выбранного рецепта несовместимые входные **предметы, жидкости и газы не удаляются автоматически**.
- Если игрок имеет ручной доступ к ресурсам, он сам извлекает их; при смене рецепта машина не обязана очищать хранилище за него.
- Для мультиблоков **без ручного доступа** машина пытается вернуть ненужные ресурсы через **первый подходящий разрешённый выход соответствующего ресурса**; при частичной передаче проверяет последующие подходящие выходы, остаток безопасно хранится. Это сценарий возврата, отличающийся от Round Robin обычного АвтоВыхода.
- Выдача несовместимых ресурсов не должна мешать уже выполняющейся операции, которая завершается по ранее зафиксированным правилам.
- Некоторые механизмы могут предоставить **явную команду игрока на принудительное опустошение выбранного хранилища**. Это всегда **полный сброс**, во всех будущих версиях; частичное удаление через GUI не предусматривается.
- Сброс уничтожает содержимое только разрешённого хранилища после серверной проверки доступа/команды; не затрагивает ресурсы активной операции или ожидающий атомарной выдачи набор результатов.
- Логическое резервирование учитывается: нельзя уничтожать зарезервированный запас без корректного снятия/запрета резерва по политике механизма.

## Границы
- Ручное выкачивание нужного количества во внешнюю ёмкость — **обычное извлечение/сервисный доступ**, а не частичный сброс.
- Конкретный GUI подтверждения и набор механизмов с функцией сброса не утверждены.
