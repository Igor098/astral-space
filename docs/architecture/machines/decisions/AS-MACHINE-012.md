# AS-MACHINE-012 — Общие и индивидуальные выходные хранилища

**Статус:** утверждено  
**Область:** архитектура машин Astral Space  
**Последнее согласование:** 2026-11-01  
**Связанные решения:** [Реестр ADR](../README.md#реестр-решений)


## Решение
- Многокамерные машины могут использовать **общие выходные хранилища**, **индивидуальные хранилища каждой камеры** или **комбинацию**.
- При общем выходе одновременные завершения конкурируют за вместимость безопасно: одна операция либо выдаёт **полный** набор, либо переходит в `WAITING_FOR_OUTPUT`.
- В индивидуальной схеме заполнение выхода одной камеры не блокирует выдачу другой, если общий ресурсный контур позволяет.
- Атомарность результатов сохраняется **на уровне одной операции**, а не всего многокамерного механизма.

## Границы
- Точный порядок разрешения одновременных попыток завершения в общем выходном буфере пока не определён.


---
**Примечание:** это архитектурное решение, не утверждение о наличии готовой Java-реализации.
