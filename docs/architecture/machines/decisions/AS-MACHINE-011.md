# AS-MACHINE-011 — Round Robin распределения энергии между камерами

**Статус:** утверждено  
**Область:** архитектура машин Astral Space  
**Последнее согласование:** 2026-11-01  
**Связанные решения:** [Реестр ADR](../README.md#реестр-решений)


## Решение
- Для независимых камер с общим энергетическим буфером применяется Round Robin при назначении возможности выполнить **полностью оплаченный рабочий такт**.
- Если рабочий такт требует `N FE`, камера получает ровно необходимую доступную мощность/энергию в пределах правил машины или не продвигает прогресс и не расходует часть тактовой цены.
- Если энергии не хватает, операция **приостанавливается**, не отменяется.
- Камера в `WAITING_FOR_OUTPUT` не расходует рабочую энергию.
- Бюджет энергии общий; конкуренция нескольких камер не может допускать двойного списания.
- Разные камеры могут иметь разные затраты FE за рабочий такт. Round Robin обеспечивает чередование возможности, **не равное распределение FE**.

## Границы
- Общий буфер и ограничения FE/t должны быть согласованы с внешним Push/Pull и внутренними потребителями; не считать приход энергии в текущем такте единственным источником — накопленный запас тоже доступен по правилам машины.
- Позиция очереди/порядок запуска и специфичные энергозатраты не фиксируются как Java API.


---
**Примечание:** это архитектурное решение, не утверждение о наличии готовой Java-реализации.
