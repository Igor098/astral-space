# AS-MACHINE-010 — Round Robin между камерами и необязательное резервирование

**Статус:** утверждено  
**Область:** архитектура машин Astral Space  
**Последнее согласование:** 2026-11-01  
**Связанные решения:** [Реестр ADR](../README.md#реестр-решений)


## Решение
- При общем входном запасе Round Robin выдаёт камерам **очередь на попытку запуска операции**, а не делит сырьё поштучно.
- Для каждого запуска необходим **полный комплект ингредиентов выбранного рецепта**, включая несколько разных предметов; камера либо атомарно получает все ингредиенты, либо не получает ничего.
- Камера с недостаточным набором пропускается, чтобы остальные могли проверить свои рецепты.
- Чередование не гарантирует одинаковое количество успешно запущенных операций и не устраняет ресурсное голодание сложных рецептов само по себе.
- **Логическое резервирование** ингредиентов допускается архитектурой, но не является обязательным для всех механизмов.
- Резервирование не равно расходованию: ресурсы остаются в хранилище, но зарезервированные количества исключаются из доступного другим камерам остатка. Фактическое списание происходит только при запуске.
- Отмена резервирования не уничтожает/не дублирует ресурсы. Политика резервирования определяется машиной.

## Границы
- Алгоритм накопления резерва, приоритеты, срок жизни резервирования и защита от deadlock требуют отдельного проектирования только для машин с этой функцией.
- Все дальнейшие смешанные рецепты применяют атомарность [AS-MACHINE-013](AS-MACHINE-013.md).
