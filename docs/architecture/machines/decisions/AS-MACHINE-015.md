# AS-MACHINE-015 — Один газовый резервуар — один газ

**Статус:** утверждено  
**Область:** архитектура машин Astral Space  
**Последнее согласование:** 2026-11-01  
**Связанные решения:** [Реестр ADR](../README.md#реестр-решений)


## Решение
- Один газовый резервуар одновременно хранит **только один тип газа**.
- Совпадающий газ может доливаться через разные разрешённые входы в пределах вместимости и скорости передачи.
- Поступление иного газа в непустой резервуар отклоняется; после полного опустошения возможен приём другого **допустимого** газа.
- Несколько разных газов для одного рецепта требуют отдельных резервуаров либо иных явно спроектированных механизмов; **самопроизвольное смешивание запрещено**.
- Понятие газовой смеси, если оно понадобится, будет отдельной специальной механикой, не стандартным поведением обычного резервуара.


---
**Примечание:** это архитектурное решение, не утверждение о наличии готовой Java-реализации.
