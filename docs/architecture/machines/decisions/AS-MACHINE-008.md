# AS-MACHINE-008 — Независимые камеры и совместная операция

**Статус:** утверждено  
**Область:** архитектура машин Astral Space  
**Последнее согласование:** 2026-11-01  
**Связанные решения:** [Реестр ADR](../README.md#реестр-решений)


## Решение
- Архитектура поддерживает **независимые рабочие камеры**: каждая может иметь свой рецепт, прогресс, активную операцию и ожидающий набор результатов.
- Также поддерживается **единая операция нескольких рабочих модулей**, например для ускорения или повышения производительности согласно механике конкретной машины.
- Четыре камеры, которые независимо выполняют одинаковый рецепт, всё равно являются независимыми операциями.
- Атомарность выдачи действует в рамках **одной операции**, а не глобально для всех камер.
- Одна камера, ожидающая освобождения своего выхода, не должна сама по себе останавливать остальные, если их допускают общие ресурсные ограничения.
- Каждая независимая операция сохраняет собственное состояние.

## Границы
- Число камер, правила ускорения и точное потребление определяются конкретной машиной.
- Алгоритмы распределения общего сырья и энергии — [AS-MACHINE-010](AS-MACHINE-010.md), [AS-MACHINE-011](AS-MACHINE-011.md).
