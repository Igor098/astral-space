# AS-MACHINE-004 — Маршрутизация между гранями и внутренними хранилищами

**Статус:** утверждено  
**Область:** архитектура машин Astral Space  
**Последнее согласование:** 2026-11-01  
**Связанные решения:** [Реестр ADR](../README.md#реестр-решений)


## Решение
- Игрок настраивает доступные **грани и маршруты**, а механизм определяет, к каким слотам/резервуарам обращается маршрут.
- Несколько граней `INPUT` могут направлять ресурс в **один** входной слот/резервуар; несколько граней `OUTPUT` могут брать результат из **одного** выходного слота/резервуара.
- Самостоятельных копий инвентаря для каждой грани нет: все маршруты видят актуальное содержимое общего хранилища.
- В электропечи с двумя слотами внешние операции: вставка — только во входной слот; извлечение — только из выходного слота.
- В более сложных машинах возможны именованные логические группы (`input`, `output`, `fuel`, `coolant`); не требуем от игрока настройки каждого слота.
- АвтоВход и АвтоВыход используют те же ограничения маршрутизации; не являются обходным доступом.

## Границы
- Точный UI выбора группы в сложных машинах не утверждён.
- Ручные действия игрока с GUI не тождественны внешней автоматизации.


---
**Примечание:** это архитектурное решение, не утверждение о наличии готовой Java-реализации.
