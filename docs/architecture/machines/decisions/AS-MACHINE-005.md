# AS-MACHINE-005 — Round Robin для активной выгрузки предметов и жидкостей

**Статус:** утверждено  
**Область:** архитектура машин Astral Space  
**Последнее согласование:** 2026-11-01  
**Связанные решения:** [Реестр ADR](../README.md#реестр-решений)


## Решение
- Активная выгрузка использует **Round Robin** по разрешённым маршрутам АвтоВыхода; выбирать стратегию в GUI игроку **не предлагается**.
- Ресурс из одного источника может направляться на несколько выходных граней; заполненные, недоступные и неподходящие получатели пропускаются, не блокируя остальные.
- Очерёдность **старта обхода** сдвигается между циклами. Равный шанс на попытку не означает равные количества доставленного ресурса.
- Максимальный объём за цикл/такт ограничивается **общим бюджетом источника**, а не умножается на число выходов. Размер отдельной передачи может иметь свой лимит.
- Очереди для предметов и жидкостей независимы; независимые ресурсные группы могут иметь отдельное состояние планировщика.
- Передачи транзакционно безопасны. Неудача не должна удалять ресурс; изменения фактического хранилища подтверждаются корректно.
- Позиция очереди не обязана сохраняться в NBT: после загрузки допустим новый старт.
- Периодичность опроса задаётся характеристиками механизма; не сканируем все соседние блоки без необходимости каждый тик.

## Границы
- Для **газов** согласно [AS-MACHINE-014](AS-MACHINE-014.md) применим тот же общий принцип маршрутизации/автоматизации, но конкретный алгоритм выгрузки и единицы/скорости газов проектируются отдельно; этот ADR изначально утверждал предметы и жидкости.
- Внешний Pull со стороны трубы не подчиняется расписанию внутреннего АвтоВыхода: очередность запросов инициирует труба.
- Привязка планировщика к `portId`, детализация повторных проходов и квантов распределения требуют проектирования при реализации.


---
**Примечание:** это архитектурное решение, не утверждение о наличии готовой Java-реализации.
