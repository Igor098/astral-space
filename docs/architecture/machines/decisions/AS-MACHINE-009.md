# AS-MACHINE-009 — Общие, раздельные и смешанные входные хранилища

**Статус:** утверждено  
**Область:** архитектура машин Astral Space  
**Последнее согласование:** 2026-11-01  
**Связанные решения:** [Реестр ADR](../README.md#реестр-решений)


## Решение
- Независимые камеры могут брать ингредиенты из **общего входного буфера**, из **индивидуальных хранилищ** или из **комбинированной конфигурации**.
- Простейшим типовым сценарием может быть общий буфер, но он не обязателен.
- Один физический запас нельзя ошибочно копировать в каждую камеру: фактические количества едины для разделяемого хранилища.
- Запуск операции по-прежнему атомарно изымает нужный набор из соответствующих источников.
- Для независимых хранилищ не нужна конкуренция за общий пул предметов; смешанный случай учитывает обе части.

## Границы
- Конкретное размещение инвентарей/резервуаров в BlockEntity или контроллере мультиблока пока не определено.


---
**Примечание:** это архитектурное решение, не утверждение о наличии готовой Java-реализации.
