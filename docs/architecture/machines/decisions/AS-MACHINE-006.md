# AS-MACHINE-006 — АвтоВход с закреплением активного предмета

**Статус:** утверждено  
**Область:** архитектура машин Astral Space  
**Последнее согласование:** 2026-11-01  
**Связанные решения:** [Реестр ADR](../README.md#реестр-решений)


## Решение
- Для механизмов с **одним слотом сырья** первый успешно выбранный ресурс становится активным и получает приоритет перед другими предметами.
- Активный предмет машина пытается извлекать **со всех разрешённых и доступных граней АвтоВхода**, а не сначала полностью из одного сундука. Между источниками этого **же** предмета применяется Round Robin.
- Источники могут ограничивать пропускную способность; суммарный приём дополнительно ограничен свободным местом и общим лимитом машины.
- Равенство предметов **строгое**: тот же тип предмета и значимые компоненты; количество в стаке не входит в идентичность. Похожий рецепт и теги не делают разные предметы одинаковыми.
- Если все источники перестают **фактически отдавать** активный предмет, механизм **не ждёт его бесконечно**. Уже лежащий во входном слоте ресурс дорабатывается; при освобождении слота машина может выбрать другой реально доступный ресурс.
- **Полный входной слот** или собственное ограничение приёма машины не считаются доказательством, что источники перестали отдавать предмет.
- Внешняя пассивная вставка через предметный `INPUT` не может нарушать активный приоритет, пока он действует. Ручной доступ игрока — отдельная политика.
- Для машин с двумя/тремя обязательными ингредиентами правило единственного активного ресурса **не действует**: им разрешён одновременный приём различных компонентов рецепта.

## Последствия
- Наличие предметов во внешнем сундуке само по себе не означает, что их можно извлечь. Нулевой результат всех реальных попыток допускает смену типа, когда внутренний слот освободится.
- Конкретные оптимизации обнаружения доступности и реакция на внешний Push не должны менять смысл этого правила.
