# AS-MACHINE-013 — Смешанные входные ингредиенты и атомарный запуск

**Статус:** утверждено  
**Область:** архитектура машин Astral Space  
**Последнее согласование:** 2026-11-01  
**Связанные решения:** [Реестр ADR](../README.md#реестр-решений)


## Решение
- Рецепт может одновременно требовать **предметы, жидкости и газы** в любых поддерживаемых конкретной машиной сочетаниях.
- Проверка и списание **всех расходуемых** входных ресурсов координируются одной атомарной операцией запуска, даже если физически ресурсы обслуживаются разными хранилищами/компонентами.
- При нехватке хотя бы одного обязательного ингредиента запуск не происходит и **ничего не списывается**.
- Нерасходуемые инструменты, чертежи и катализаторы проверяются по правилам рецепта без автоматического уничтожения.
- После подтверждённого списания создаётся активная операция с зафиксированными существенными параметрами.

## Границы
- Общая транзакционная координация не требует одного универсального `ResourceComponent<T>` для всех типов ресурсов.
- Газовая система реализуется отдельно от жидкостной, см. [AS-MACHINE-014](AS-MACHINE-014.md).


---
**Примечание:** это архитектурное решение, не утверждение о наличии готовой Java-реализации.
