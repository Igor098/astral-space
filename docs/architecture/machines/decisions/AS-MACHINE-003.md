# AS-MACHINE-003 — Грани, АвтоВход, АвтоВыход и энергетическая доставка

**Статус:** утверждено  
**Область:** архитектура машин Astral Space  
**Последнее согласование:** 2026-11-01  
**Связанные решения:** [Реестр ADR](../README.md#реестр-решений)


## Решение
- Игрок управляет доступностью маршрутов **по каждой разрешённой грани отдельно**; все грани не становятся входами/выходами автоматически.
- У предметных, жидкостных и газовых маршрутов отдельно существуют **пассивные разрешения** (`INPUT`: сосед сам вставляет; `OUTPUT`: сосед сам извлекает) и, где это поддерживается машиной, **активные действия** (`АвтоВход`: машина вытягивает; `АвтоВыход`: машина выталкивает).
- АвтоВход и АвтоВыход включаются **отдельно на соответствующих маршрутах/гранях**, изначальное автоматическое включение всех граней запрещено. Поддержка опции зависит от машины.
- Автоматические действия не обходят допустимые для маршрута операции и внутреннюю политику хранилищ.
- Для **энергии** не создаём пользовательские флаги АвтоВход/АвтоВыход. Производители и накопители при активных энергетических `OUTPUT` инициируют Push; потребители принимают FE через `INPUT`. Внешние кабели могут делать Pull/Push по соответствующим разрешениям.
- Источник FE инициирует реальную передачу, «автоматического протекания» через одну настройку порта нет. Общий лимит FE/t обязателен для конкурирующих Push/Pull.

## Границы
- Для необычных машин возможно особое активное извлечение FE, но оно не становится стандартным режимом GUI.
- Интервалы автоматизации и UI-кнопки не фиксируются здесь.

**Примечание:** это архитектурное решение, не утверждение о наличии готовой Java-реализации.
