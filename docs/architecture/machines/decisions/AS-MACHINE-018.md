# AS-MACHINE-018 — Роли INPUT, OUTPUT, BIDIRECTIONAL для резервуаров

**Статус:** утверждено  
**Область:** архитектура машин Astral Space  
**Последнее согласование:** 2026-11-08  
**Связанные решения:** [Реестр ADR](../README.md#реестр-решений)


## Решение
- Внутренние жидкостные и газовые резервуары могут иметь производственную роль `INPUT`, `OUTPUT` или `BIDIRECTIONAL`.
- `INPUT` принимает ингредиенты и не предоставляет обычному внешнему `OUTPUT` права выкачивать их.
- `OUTPUT` хранит продукцию; произвольная внешняя закачка в него не допускается.
- `BIDIRECTIONAL` допускается для накопителей и специальных механизмов **только если это предусмотрено конструкцией**.
- **Роль хранилища**, **маршрут доступа на грани** и **производственная политика** — разные измерения; двунаправленный бак не делает все грани двунаправленными.
- Для `FLUID` и `GAS` на одной грани одновременно разрешён только один внешний режим: `INPUT`, `OUTPUT`, `DISABLED` либо взаимоисключающий `SERVICE` (если поддерживается). `INPUT + OUTPUT` одного типа на одной грани запрещено даже при разных баках; `SERVICE` регулирует [AS-MACHINE-020](AS-MACHINE-020.md).
- Роль внутреннего резервуара `BIDIRECTIONAL` не создаёт внешний режим `BOTH`: разные грани могут предоставлять разные направления.


---
**Примечание:** это архитектурное решение, не утверждение о наличии готовой Java-реализации.
