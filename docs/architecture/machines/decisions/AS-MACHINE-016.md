# AS-MACHINE-016 — Фиксированные и динамические газовые резервуары

**Статус:** утверждено  
**Область:** архитектура машин Astral Space  
**Последнее согласование:** 2026-11-01  
**Связанные решения:** [Реестр ADR](../README.md#реестр-решений)


## Решение
- Машина может задавать резервуарам **фиксированные типы** газа: пустой резервуар принимает только назначенный газ.
- Либо разрешить **динамическое назначение**: первый допустимый газ занимает подходящий пустой резервуар; следующий иной газ может занять другой.
- В динамической группе один и тот же газ не заполняет автоматически несколько резервуаров, если только рецепт или конструкция прямо не предусматривают исключение.
- Динамическая загрузка учитывает выбранный рецепт, чтобы лишние газы не занимали резервуары, необходимые другим ингредиентам.
- После полного опустошения динамический резервуар может получить новое назначение.
- Фиксированная/динамическая модель выбирается **конкретным механизмом**, не гранью или трубой.


---
**Примечание:** это архитектурное решение, не утверждение о наличии готовой Java-реализации.
