# AS-MACHINE-014 — Газ — самостоятельный тип ресурса

**Статус:** утверждено  
**Область:** архитектура машин Astral Space  
**Последнее согласование:** 2026-11-01  
**Связанные решения:** [Реестр ADR](../README.md#реестр-решений)


## Решение
- **Газ** не маскируется под жидкость: самостоятельные определения ресурса, резервуары, портовые маршруты, правила передачи и хранения.
- Газ может быть ингредиентом или результатом рецепта наравне с предметами и жидкостями.
- Для газов действуют общие принципы разрешённых граней, сервисного доступа, автоматизации, безопасных транзакций и атомарности рецептов.
- Преобразование газа в жидкость (сжижение) или обратно происходит через **специальный рецепт/операцию**, а не через автоматическую совместимость двух резервуаров.
- Для газа NeoForge 1.21.11 **не предоставляет стандартную block capability** наряду с Item/Fluid/Energy, поэтому способ межмодовой интеграции/собственная capability — отдельное решение.

## Границы
- Давление, температура, объёмные единицы, физические симуляции, трубы, баллоны и смешивание газов не утверждены этим ADR.


---
**Примечание:** это архитектурное решение, не утверждение о наличии готовой Java-реализации.
