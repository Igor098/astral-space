# AS-MACHINE-002 — Независимые предметные INPUT и OUTPUT на одной грани

**Статус:** утверждено  
**Область:** архитектура машин Astral Space  
**Последнее согласование:** 2026-11-01  
**Связанные решения:** [Реестр ADR](../README.md#реестр-решений)


## Решение
- Входной и выходной маршруты предметов различаются независимо от физической грани.
- Одна грань может одновременно предоставлять предметные `INPUT` и `OUTPUT`, если это разрешено политикой механизма.
- `INPUT` позволяет внешнюю вставку только в предназначенные для входа группы слотов; `OUTPUT` — внешнее извлечение только из выходных групп.
- Для предметов **не вводится** один общий режим `BOTH`, подменяющий два отдельных маршрута.
- Если NeoForge запрашивает одну предметную block capability для грани, предоставляемый обработчик должен **компоновать допустимые маршруты**, корректно фильтровать insert/extract и не раскрывать запрещённые слоты.

## Границы
- Несколько логических маршрутов одного вида на грани — внутренняя модель; API внешней capability не обязан содержать понятие `routeId`.
- Политика принадлежности слотов задаётся механизмом, а не трубой.


---
**Примечание:** это архитектурное решение, не утверждение о наличии готовой Java-реализации.
