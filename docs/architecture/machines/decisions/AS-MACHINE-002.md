# AS-MACHINE-002 — Взаимоисключающие предметные режимы на грани

**Статус:** утверждено  
**Область:** архитектура машин Astral Space  
**Последнее согласование:** 2026-11-08  
**Связанные решения:** [Реестр ADR](../README.md#реестр-решений)

## Решение
- Для `ITEM` на одной грани одновременно действует ровно один режим: `INPUT`, `OUTPUT`, `DISABLED` либо взаимоисключающий `SERVICE`, если поддерживается механизмом.
- Совмещение `ITEM INPUT + ITEM OUTPUT` на одной грани **запрещено** даже при наличии разных входных и выходных слотов внутри.
- `INPUT` разрешает внешнюю вставку только в разрешённые входные группы; `OUTPUT` — внешнее извлечение только из выходных групп; `DISABLED` запрещает обе операции.
- Отсутствующий порт конструктивно отличен от существующего отключённого порта.
- Разные грани могут обращаться к общим внутренним входным либо выходным группам без копирования запасов.
- Обработчики NeoForge side capability обязаны проверять текущий режим и ограничения слотов при **каждой** операции, даже через ранее закэшированный обработчик.

## Собственная предметная труба
- Соединение трубы относительно соседнего блока имеет режимы «Подача в блок», «Забор из блока», «Оба направления». По умолчанию — **«Оба направления»**.
- Это настройка **трубы**, не машины. «Оба направления» не разрешает одновременно `ITEM INPUT + ITEM OUTPUT` у порта машины.
- Дополнительный необязательный фильтр трубы ограничивает допустимые предметы. Без пользовательского фильтра действуют ограничения машинных слотов и рецепта.
- «Оба направления» — разрешение операций на соединении, не команда автоматически делать туда-обратно. Сети должны избегать бессмысленных возвратных циклов; для универсальных сундуков может потребоваться явное направление/фильтр.

## Границы
- Разные типы ресурса могут сосуществовать на грани (например, ITEM OUTPUT + ENERGY INPUT).
- `SERVICE` извлекает только из явно разрешённых входных групп, взаимоисключает остальные ITEM-режимы и не равен производственному OUTPUT.
- Сторонние моды обращаются к стандартным capabilities; настройки собственной трубы для них не обязательны.
- Конкретные Java API, интерфейс фильтров и алгоритмы маршрутизации пока не утверждены.

---
**Примечание:** это архитектурное решение, не утверждение о наличии готовой Java-реализации.
