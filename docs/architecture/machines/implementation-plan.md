## Этап 7. Мультиблоки, SERVICE и возвраты

- Контроллер, физические хэтчи и их стабильные логические `portId`.
- Для мультиблоков спроектировать **специализированные блоки-порты** по ресурсу и роли (энергетический вход/выход, предметный вход/выход, жидкостные порты и др.), без требования совмещать ресурсы на одном хэтче.
- Учесть несколько отдельных хэтчей с одинаковым `Direction`, сохранив уникальные `EnergyPortId` и общие ресурсы контроллера.
- SERVICE-маршрут для извлечения входных ресурсов, независимо от обычного OUTPUT.
- Правила возврата несовместимых ресурсов и явного полного сброса с серверным разрешением.

## На каждом этапе

- Сначала контракт и тесты на инварианты, затем производственный код.
- Сохранять работу Coal Generator Mk I и регрессию Push/Pull/fairness.
- Не строить совместимость с несуществующими старыми мирами.
- Обновлять ADR при реальном изменении решения, а не при каждой внутренней оптимизации.
- Нагрузочное тестирование отложено по решению разработчика до более завершённого состояния мода.
