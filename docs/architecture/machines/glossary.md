# Глоссарий

| Термин | Определение |
|---|---|
| Механизм | Логический владелец хранилищ, портов, рецептов и операций; может быть отдельным блоком или мультиблочным контроллером |
| `MachineSide` | Локальная сторона относительно ориентации машины: `FRONT`, `BACK`, `LEFT`, `RIGHT`, `TOP`, `BOTTOM` |
| `Direction` | Мировое пространственное направление, передаваемое в контекст NeoForge block capability |
| Канал | Категория ресурса, которую механизм умеет принимать/отдавать: FE, предметы, жидкость, газ |
| Порт | Устойчивая логическая точка подключения с собственной идентичностью и политикой; для FE — `EnergyPortId` |
| Маршрут | Связь внешнего доступа и разрешённой внутренней группы хранения с конкретной операцией |
| `INPUT` | В производственной логике — вход; при внешнем доступе — операция вставки в разрешённые входные хранилища |
| `OUTPUT` | В производственной логике — результат; при внешнем доступе — извлечение только разрешённых выходных ресурсов |
| `SERVICE` | Специальный маршрут для внешнего извлечения ресурсов из разрешённых входных хранилищ, **не** обычный OUTPUT |
| `BIDIRECTIONAL` | Роль отдельных специальных баков, допускающая оба направления по правилам машины; не энергия `BOTH` |
| Пассивный доступ | Внешнее устройство само инициирует вставку/извлечение через capability |
| АвтоВход | Машина активно пытается извлечь ресурс из соседнего хранилища |
| АвтоВыход | Машина активно пытается передать результат соседу |
| Общий бюджет | Ограничение суммарного объёма, не умножаемое числом подключений |
| Round Robin | Чередование начальной очередности обслуживания, а не балансировка содержимого соседей |
| Входная группа | Набор слотов/баков для допустимых ингредиентов |
| Активный тип предмета | Строго определённый предмет, которому однослотовая машина временно отдаёт приоритет |
| Выбранный рецепт | Конфигурация следующего производства; источник выбора зависит от механизма |
| Активная операция | Уже начатая работа с зафиксированным прогрессом, существенными параметрами и результатами |
| Неделимый набор результатов | Все предметные, жидкостные и газовые продукты **одной** операции; выдаются только целиком |
| `WAITING_FOR_OUTPUT` | Концептуальное состояние: прогресс 100%, полный набор готов, но внутренние выходные хранилища не могут принять его целиком |
| Логическое резервирование | Выделение части существующего запаса конкретной камере **без** физического расходования |
| Сервисное извлечение | Реальная передача выбранного количества наружу через SERVICE |
| Принудительный сброс | Явное действие игрока, безвозвратно удаляющее **всё** содержимое разрешённого выбранного хранилища |
| Миграция старых миров | Перенос старого формата сохранений; для текущего невыпущенного Astral Space **не требуется** |

## Дополнительные термины: визуальные и физические подключения

| Термин | Значение |
|---|---|
| Визуальная область (visual slot/region) | Названная часть поверхности машины, чью модель можно независимо заменить/добавить; сама по себе не гарантирует право передачи |
| Embedded | Встроенный вариант: вместо штатной заглушки/панели отображается выбранный модуль |
| Overlay | Накладной вариант: модуль добавляется поверх постоянной основы, без обязательной замены её геометрии |
| Физическая точка стыковки | Локальное положение конца коммуникации на грани машины; не тождественно `Direction` и `PortId` |
| Составной транспортный блок | Одна клетка мира, способная содержать несколько **наших** коммуникаций разных ресурсных типов |
| Канал коммуникации | Отдельная трасса/сеть одного типа транспорта внутри составного блока; не смешивается с соседней трассой |
| Сечение пучка | Взаимное положение 1–5 линий **в торце транспортного блока**, не на поверхности машины |
| Стыковочная обёртка | Автоматически выбираемая геометрия совместного окончания или перехода коммуникаций возле машины; не отдельная пользовательская настройка |
| Сторонний capability | Стандартный ресурсный интерфейс машины, доступный внешним модам по типу ресурса и стороне без выбора точных XY-координат порта |
| VisualTestBlock | Локальный демонстрационный блок проверки независимой модели, не production-API машин |

## Уточнения терминов 2026-11-08

| Термин | Значение |
|---|---|
| Режим порта машины | Единственный режим одного типа на одной грани: `INPUT`, `OUTPUT`, `DISABLED` либо взаимоисключающий `SERVICE` |
| Направление соединения трубы | Относительно подключённого блока: «Подача в блок», «Забор из блока», «Оба направления» (**по умолчанию**) |
| Фильтр соединения | Необязательное дополнительное ограничение допустимых ресурсов; не отменяет правила машины |
| Жидкостная сеть | Логически связанная трасса, переносящая только один вид жидкости одновременно |
| Освобождение типа жидкости | Сброс текущего вида жидкости после **полного** опустошения всей сети и завершения операций/резервов |
