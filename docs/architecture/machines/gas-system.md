# Газовая подсистема

ADR: [014](decisions/AS-MACHINE-014.md), [015](decisions/AS-MACHINE-015.md), [016](decisions/AS-MACHINE-016.md), [018](decisions/AS-MACHINE-018.md), [019](decisions/AS-MACHINE-019.md), [020](decisions/AS-MACHINE-020.md).

## Отдельный ресурс, не жидкость

Газ — **самостоятельная** категория. От жидкостей заимствуем только полезные правила маршрутов, резервуаров и транзакционной безопасности; не кодируем газ как фиктивную жидкость.

Для каждого газового резервуара:

1. Внутри одновременно **один тип газа**.
2. Иной газ отклоняется, пока резервуар не опустеет.
3. Разрешены фиксированное и динамическое назначения.
4. В динамической группе не дублируем газ по резервуарам без оснований рецепта или конструкции.
5. Сложный рецепт может использовать несколько отдельных газовых баков одновременно.
6. Роль бака `INPUT`/`OUTPUT`/`BIDIRECTIONAL` не превращает обычный OUTPUT в сервисный вывод входных газов.

## Автоматизация

Поддерживаем принципы разрешённых граней и опциональных действий АвтоВход/АвтоВыход. Конкретные API газовых обработчиков, единицы количества, передачу через трубы, интервалы автоматизации и физические параметры **проектируем отдельно**.

## Рецепты

Газовые ингредиенты включаются в атомарную проверку и списание при запуске. Газовые продукты включаются в неделимый набор выдачи одной операции. Пример: реактор отдаёт предмет, жидкость и газ; при заполненном газовом баке **ничего из набора не выдаётся**.

Сжижение/испарение — преобразование в рамках производственной операции, а не общая совместимость жидкостных и газовых ёмкостей.

## Технологическая совместимость

Официальный перечень встроенных NeoForge 1.21.11 block capabilities содержит предметы, жидкости и FE; стандартная capability для газа **не заявлена**. Нужно отдельное проектное решение о собственном API/межмодовой совместимости.

Источник: https://docs.neoforged.net/docs/1.21.11/inventories/capabilities/

## Вопросы на будущее

Давление/температура, сжимаемость, единицы газа, вещества и компоненты, собственные pipes/баллоны и реальная газовая смесь **не утверждены**.

## Режим газа на грани (2026-11-08)

Для GAS на одной грани выбран единственный режим `INPUT`, `OUTPUT`, `DISABLED` либо взаимоисключающий `SERVICE`. Роль внутреннего бака `BIDIRECTIONAL` не делает грань двунаправленной. Газовая сеть проектируется отдельно; не переносим автоматически на неё требование одной жидкости на жидкостную сеть.
