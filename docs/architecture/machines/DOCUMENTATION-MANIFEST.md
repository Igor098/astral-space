# Манифест поставки документации

**Первоначальная дата:** 2026-11-01.
**Актуализация энергетической подсистемы:** 2026-11-03.

- `decisions/AS-MACHINE-001.md` – `AS-MACHINE-020.md`: **20 утверждённых ADR**.
- Тематические документы: описание общей архитектуры, интерфейсов ресурсов, FE, предметов, жидкостей, газов,
  производственных операций, автоматизации, сохранения/сети.
- `energy-existing-decisions.md`: указатель на **канонический** файл
  `../energy/AstralSpace_Energy_Architecture_Decisions.md`; история миграции `EnergyPortId` и статус технического долга
  поддерживаются только в канонической версии.
- `test-matrix.md`: требования к будущим тестам + отметка о локально подтверждённых 66 FE-регрессиях; остальная матрица
  не объявляется выполненной.
- `implementation-plan.md`: выполненная миграция `EnergyPortId`, текущая стадия FE-компонентов и дальнейшие этапы
  интеграции; само обновление документов не изменяет production-код.
- `open-questions.md`: неутверждённые вопросы; `TECH-DEBT-ENERGY-001` помечен как закрытый для менеджера, а вопросы
  универсального FE-адаптера и мультиблоков остаются открытыми.

**Замечание:** согласованность отдельных решений не означает окончательную спецификацию всех Java/API-деталей. Все не
выбранные варианты явно обозначены как открытые.

**Совместимость:** структура `docs/architecture/machines/` и 20 исходных ADR сохранена. Канонический энергетический ADR
находится в соседнем каталоге `docs/architecture/energy/`.
